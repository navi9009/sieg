# SIEG.AI

SIEG.AI is an AI-powered platform designed to help students plan and manage their journey toward studying in Germany.
It provides personalized applicant profiles, document management, AI-powered document analysis, and a personal AI advisor.
Users can track their qualifications, understand their next steps, and get guidance throughout the application process.

https://sieg.vercel.app

## Built With

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- AI
- Vercel
